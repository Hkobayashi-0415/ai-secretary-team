# API Changes (2025-10-19)

Conversations
- `GET /api/v1/conversations/{id}/messages/page`
  - Query: `before_id` (UUID, optional), `limit` (int, default 20)
  - Behavior: if `before_id` is missing or does not belong to the same conversation, returns `200` with `messages: []`, `has_more: false`.
- `PATCH /api/v1/conversations/{id}`
  - 404 when conversation is missing with `{ "detail": "Conversation not found" }`.
- `DELETE /api/v1/conversations/{id}`
  - 404 when conversation is missing with `{ "detail": "Conversation not found" }`.

WebSocket Chat
- `GET /api/v1/ws/chat?conversation_id=...`
  - If conversation does not exist, the server closes with code `4404`.
  - When an empty text payload is received, emits `{ "type": "error", "message": "empty text" }`.

Error Handling & Logging
- Global exception handlers added for `HTTPException` and generic `Exception`.
- Structured JSON logging via `app.core.logging.BasicLogger`.
